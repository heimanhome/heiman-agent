# heiman-identity-register

家庭成员身份注册主流程。

## 何时激活

| 触发场景 | 用户说了类似… |
| -------- | ------------- |
| **上传图片/视频** | "这是爸爸" "给妈妈录个视频" "拍下豆豆的样子" |
| **回应陌生人推送** | "那是爸爸" "不认识" "是快递员" |
| **直接表达注册意图** | "建档案" "录入家人" "记下样子" "让系统认识他" |
| **指认摄像头画面** | "画面里的是妈妈" "左边的是爸爸" |
| **从陌生人记录挑选** | "把上次那个陌生人设为爸爸" "找出最近出现的人" |

## 核心工作流

### 步骤 1 · 意图确认

确认用户的注册意图：

> "你想让系统认识谁？请提供照片或视频。"

### 步骤 2 · 身份信息收集

收集注册所需的信息：

| 信息 | 收集方式 |
| ---- | -------- |
| **姓名** | 用户直接提供 |
| **角色** | 用户选择或系统推荐 |
| **样本图片/视频** | 用户上传或从摄像头抓拍 |

### 步骤 3 · 样本采集

```bash
# 上传图片样本
heiman-cli person register --name <name> --role <role> --image <url>

# 上传视频样本
heiman-cli person register --name <name> --role <role> --video <url>

# 从摄像头抓拍
heiman-cli person register --name <name> --role <role> --camera <did>
```

### 步骤 4 · 验证确认

确认注册信息：

> "正在注册 xxx（角色：xxx），请确认照片是否清晰？"

### 步骤 5 · 完成注册

```bash
heiman-cli person register --name <name> --role <role> --confirm
```

## 角色推荐

根据用户描述自动推荐角色：

| 描述信号 | 推荐角色 |
| -------- | -------- |
| "爸爸"、"父亲" | 爸爸 |
| "妈妈"、"母亲" | 妈妈 |
| "儿子"、"男孩"、"儿子" | 儿子 |
| "女儿"、"女孩"、"女儿" | 女儿 |
| "爷爷"、"祖父" | 爷爷 |
| "奶奶"、"祖母" | 奶奶 |

## 异常处理

| 异常 | 处理 | 回复 |
| ---- | ---- | ---- |
| 照片不清晰 | 要求重新上传 | "照片不够清晰，请重新拍摄" |
| 角色不明确 | 询问用户 | "请问 xxx 是什么角色？" |
| 已有同名成员 | 询问是否覆盖 | "已存在同名成员，是否覆盖？" |
| 样本数量不足 | 要求补充样本 | "请至少提供 3 张不同角度的照片" |

## 边界

- ✅ 支持图片、视频、摄像头抓拍三种注册方式
- ✅ 支持从陌生人记录中选择注册
- ❌ 不支持批量注册
- ⚠️ 删除已注册身份需二次确认

## 示例

### 上传图片注册

用户："这是爸爸"（上传照片）

```bash
heiman-cli person register --name "爸爸" --role "爸爸" --image "https://..."
```

### 回应陌生人推送

用户："那是爸爸"（回应陌生人通知）

```bash
# 从陌生人记录中提取照片
heiman-cli person register --name "爸爸" --role "爸爸" --stranger-id <id>
```
