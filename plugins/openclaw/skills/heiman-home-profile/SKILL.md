# heiman-home-profile

家庭档案管理，自动识别并记录家庭成员相关信息。

## 何时激活

| 意图 | 用户说了类似… |
| ---- | ------------- |
| **record** | "我喜欢喝咖啡" "妈妈有高血压" "爸爸每天早上跑步" |
| **query** | "爸爸的用药记录" "家里有哪些规矩" "豆豆喜欢什么" |
| **update** | "妈妈的血压药改了" "把爸爸的跑步时间改到晚上" |
| **delete** | "删除这条记录" "把豆豆的那个习惯去掉" |

## 核心工作流

### 步骤 1 · 意图识别

从用户对话中识别档案操作意图：

| 意图信号 | 识别规则 |
| -------- | -------- |
| 记录 | 提及喜好、习惯、身体状况、作息、规则等信息 |
| 查询 | 使用"查"、"看"、"找"、"什么"等查询词 |
| 更新 | 使用"改"、"修改"、"更新"、"换"等更新词 |
| 删除 | 使用"删"、"删除"、"去掉"、"不要"等删除词 |

### 步骤 2 · 信息提取

提取档案信息的关键要素：

| 要素 | 提取规则 | 示例 |
| ---- | -------- | ---- |
| **主体** | 家庭成员名称或角色 | "爸爸"、"妈妈"、"豆豆"、"我" |
| **类别** | 信息分类 | "喜好"、"习惯"、"健康"、"作息"、"规则" |
| **内容** | 具体信息描述 | "喜欢喝咖啡"、"有高血压"、"每天早上跑步" |
| **时间** | 时间相关信息 | "每天早上"、"周末"、"睡前" |

### 步骤 3 · 档案操作

根据意图执行相应操作：

| 操作 | CLI 命令 |
| ---- | -------- |
| 创建记录 | `heiman-cli profile create --person <name> --category <cat> --content <json>` |
| 查询记录 | `heiman-cli profile get --person <name> [--category <cat>]` |
| 更新记录 | `heiman-cli profile update --id <id> --content <json>` |
| 删除记录 | `heiman-cli profile delete --id <id>` |

## 档案类别

| 类别 | 描述 | 示例 |
| ---- | ---- | ---- |
| **preference** | 个人喜好 | "喜欢喝绿茶"、"喜欢看电影" |
| **habit** | 生活习惯 | "每天早上跑步"、"睡前阅读" |
| **health** | 健康状况 | "有高血压"、"对花粉过敏" |
| **schedule** | 作息规律 | "每天 7 点起床"、"周末睡懒觉" |
| **rule** | 家庭规则 | "晚上 10 点后不看电视"、"进门换鞋" |

## 特殊处理

### 第一人称处理

用户使用"我"时，通过 `heiman-cli person list` 确定当前用户身份。

### 隐式记录

当用户提到档案相关信息但未明确要求记录时，询问确认：

> "我听到你提到爸爸每天早上跑步，需要记录到家庭档案吗？"

### 信息冲突

发现已有记录与新信息冲突时，询问处理方式：

> "档案中已有爸爸早上跑步的记录，现在你说改到晚上，是更新还是添加新记录？"

## 示例

### 记录示例

用户："妈妈有高血压，每天早上吃降压药"

```bash
heiman-cli profile create --person "妈妈" --category "health" \
  --content '{"condition":"高血压","medication":"降压药","schedule":"每天早上"}'
```

### 查询示例

用户："妈妈的健康档案"

```bash
heiman-cli profile get --person "妈妈" --category "health"
```
